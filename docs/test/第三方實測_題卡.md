# 第三方實測題卡

（作業方式見 `docs/test/第三方實測_說明.md`。）

## 1. 傳給受測者的三則訊息

依序一則一則傳。整段複製，不要改字，這樣每位受測者查到的結果才會一樣。

**訊息 1**

```text
雲林縣從四月六日開始，晚上十點至清晨六點停水，所以晚上早點洗澡，洗衣，儲水備用，早上停水的時間較短，對大家比較不影響。
```

**訊息 2**

```text
您的網購刷卡分期設定錯誤將連續扣款12期，請立即聯繫客服人員協助解除
```

**訊息 3**（自編的測試訊息，結束後要跟受測者說明）

```text
台中市政府交通局宣布，下個月起市區公車將新增三條夜間路線，行駛到凌晨一點，詳細時刻表將公布在交通局官網。
```

## 2. 主持人念的題目

開場先說網址：「請用手機打開 fakenewsverify.vercel.app。」

- **T1**：「你在 LINE 收到第一則訊息，想知道是不是真的。請用這個網站查，查完告訴我網站怎麼說、根據什麼。」
- **T2**：「第二則也查一下。查完告訴我，你接下來會怎麼做？」
- **T3**：「第三則也查一下。網站的意思是什麼？你會轉傳給家人嗎？」
- **T4**：「把剛剛第一則的查證結果分享給一位朋友。」
- **T5**：「在這個網站上找一則查核機構最近查過的假訊息，念給我聽。」
- **T6（選做）**：「如果你最近收到過覺得可疑的訊息，也可以查查看。」

## 3. 問卷

### SUS 量表

請受測者依感受圈選：1＝非常不同意、2＝不同意、3＝普通、4＝同意、5＝非常同意。

1. 我想我會經常使用這個網站。
2. 我覺得這個網站沒必要地複雜。
3. 我覺得這個網站很容易使用。
4. 我想我需要有人協助才能使用這個網站。
5. 我覺得這個網站的各項功能整合得很好。
6. 我覺得這個網站有太多不一致的地方。
7. 我想大部分的人很快就能學會使用這個網站。
8. 我覺得這個網站用起來很笨拙。
9. 我使用這個網站時很有信心。
10. 我需要先學很多東西，才能開始使用這個網站。

### 開放題

1. 用的時候，最讓你困惑的地方是什麼？
2. 哪個地方對你最有幫助？
3. 你會推薦家人使用嗎？（會／不會／不確定）
