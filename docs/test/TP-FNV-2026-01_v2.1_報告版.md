## 2. 測試範圍

涵蓋文字與網址查證、結果頁與分享、Threads 機器人、知識庫與查核同步、熱門牆、資料清洗、準確率、延遲與使用者測試。

不納入本輪：圖片上傳（介面尚未開放）、每日查核貼文（FR-12）。研究限制：歷史安全題被判紅燈的比例仍有 51.9%（315／607，10-26）；本週新查核每週只有 9～41 題，信賴區間很寬，只看趨勢。
