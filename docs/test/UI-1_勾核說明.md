# UI-1 截圖勾核說明（給石岱勳）

測試計畫書 `TP-FNV-2026-01.md` 的 UI-1 要「由非實作組員逐格勾核、張宇宏覆核」。
你就是那個非實作組員，所以這件事只有你能做。

## 打勾打在哪

檔案：**`docs/test/ui_checklist.csv`**（用 Excel 直接開，已存成 UTF-8 BOM，不會亂碼）

一列一張截圖，共 89 列。你只要填這兩欄：

| 欄位 | 填什麼 |
|------|--------|
| `勾核結果` | `通過` 或 `不通過` |
| `勾核日期` | 例如 `2026-09-21` |

`勾核者` 已經先填好你的名字，`覆核者` 是張宇宏，他看完再填 `覆核結果`。

**`result` 那一欄不要動**——那是 Claude 事先做的自動預檢（每列的 `note` 都註明「目視（Claude，非組員勾核）」），
留著當對照。你的 `勾核結果` 才是這一項測試真正算數的結果。

## 每一列要看什麼

1. 打開 `file` 欄指到的那張圖（都在 `docs/test/screens/`）。
2. 對照 `screen`／`state`／`width`／`theme`，確認圖就是那個畫面、那個狀態、那個寬度與主題。
3. 逐項檢查，四點全對才寫 `通過`：
   - 文字跟規格 `docs/rebuild/01_spec.md` §8.7 的文案表一樣（錯字、多字、少字都算不通過）。
   - 沒有 §8.6 列的違規：**字級小於 13 px**、只有滑鼠移上去才看得到的說明。
   - **紅黃綠只出現在判定上**（判定塊、燈號、判定標籤）。導覽列、按鈕、一般文字不可以用紅黃綠。
   - S1 首頁與 S2 結果頁另外要跟設計稿對照：`docs/rebuild/mockup/Main.dc.html`、`Result.dc.html`、
     `ResultStates.dc.html`（用瀏覽器打開）。S3、S4、S6 只對 §8.3 的元件清單。
4. 寫 `不通過` 的時候，在 `note` 欄後面接一句話說明哪裡不對（原本的文字不要刪，接在後面就好）。
   同一個問題出現在很多列，寫一次就好，其餘列寫「同 UI-1-0xx」。

## 先看得懂的順序

從 S1 首頁開始（13 列），再 S2 結果頁（39 列，最多），最後 S3 熱門牆、S4 知識庫（各 12 列）。
一列大概一分鐘，整份約一個半小時，可以分兩次做完。

## 還不能勾的四列

檔名欄是空的那四列先跳過，它們本來就標了「未執行」或「報告後執行」：

| 列 | 為什麼還不能勾 |
|----|----------------|
| UI-1-086 | `/bot` 機器人頁還是佔位頁（票 S-11），排在報告後 |
| UI-1-087 | 知識庫「載入更多」在第二批被刪掉了，屬於範圍刪減 |
| **UI-1-088** | **深色版截圖還沒擷取完**：89 列裡只有 9 列是深色（S2 有 7 張、S1 有 1 張），S3、S4 完全沒有 |
| UI-1-089 | 就是這份勾核本身——你把上面填完，這一列才能標通過 |

**UI-1-088 是目前唯一擋住 UI-1 的技術問題**：要把 S1～S4 的深色截圖補齊。
擷取是自動的（headless Edge），跟廖晢勛說一聲就可以補，不用你手動截圖。
