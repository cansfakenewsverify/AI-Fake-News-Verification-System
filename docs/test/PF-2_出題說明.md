# PF-2 改寫句出題說明

（2026-09-20 初版；2026-09-21 依第三輪實測結果修訂，補入各種改寫手法的實際相似度）

## 這項測試在測什麼

系統的第二層快取是「語意相似」：同一則謠言換個說法再貼進來，應該認得出來、
直接沿用先前的判定，不必再呼叫 AI。PF-2 量測這一層的命中率，
通過準則為 20 句改寫句中至少 14 句（70%）命中語意層。

出題須由組員撰寫而非由 AI 助理產生（票 O-11），以避免出題者與受測系統來自同一來源。
題目定稿後不得在看到結果後修改。

## 撰寫準則

**核心原則：保留關鍵詞，只更換句型。**

一句改寫要能被語意層認出來，必須保留原文的主角、地點、數字與事件；
可以自由更換語序、連接詞與說法。想像是把這則謠言轉述給朋友：
意思一樣，但用自己的話講。

| 做法 | 對相似度的影響 |
|------|----------------|
| 換語序、換同義的動詞與連接詞 | 影響很小，通常仍在 0.85 以上 |
| 加入語氣詞（「網傳」「聽說」「有人說」） | 影響很小 |
| 刪掉主角或地點（人名、國名、機構名） | 大幅下降 |
| 刪掉數字或時間 | 大幅下降 |
| 改寫成新聞稿或公文的語氣 | 大幅下降 |
| 加入原文沒有的內容（例如後續處置、澄清） | 大幅下降 |
| 一字不改地照抄 | 不適用——見下節 |

## 為什麼不能照抄

系統的三層快取依序為：相同內容（雜湊）→ 語意相似（向量）→ AI 判讀。
與原文逐字相同的句子會在第一層就命中，**根本不會進入語意層**，
因此對 PF-2 而言等於沒有測到，計為未命中。

2026-09-21 的題組有 4 句與原文逐字相同，其相似度皆為 1.0000（滿分），
但全部命中雜湊層，對該次量測不計分。

## 出題流程

1. 以試算表開啟 `docs/test/pf2_worksheet.csv`（UTF-8 含 BOM，Windows 與 macOS 皆可直接開啟）。
2. 表中 20 列為知識庫既有的原文，在「你的改寫句」欄各寫一句改寫，長度約一至兩句話。
3. 若某列原文不適合作為題目（例如僅是對話片段而非完整謠言），可自
   `docs/test/pf2_candidates.csv` 另選一則，連同 `kb_id` 與原文一併替換，並於備註欄記錄原因。
4. 撰寫期間不得先到網站試送，也不得詢問 AI 某句是否會命中——先試再改等同於預先得知答案，
   量測結果即不可用。
5. 定稿後交回測試負責人確認，再由其執行量測。

## 量測與記錄

量測以 `code/backend/scripts/run_pf2.py` 對本機後端執行，
逐句記錄 `cache_layer` 與延遲，結果寫入 `docs/test/results/` 與測試計畫書第 6 節。
另有唯讀的 `code/backend/scripts/pf2_similarity.py` 可算出每一句的實際相似度，
用於診斷未命中的原因；該腳本不寫入資料，可重複執行。

相似度門檻 0.75 為實測校準值，不因測試未通過而調降。
