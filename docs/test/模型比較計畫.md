# 純模型比較計畫（2026-10-28）

網站的 AI 判讀現在只用 `gpt-5.6-luna`，選型依據只有 2026-09-30 兩個模型比 150 題＋41 則新查核
（`docs/test/results/model_switch_2026-09-30.md`）；而且只有一個 provider、沒有備援，當天就碰過模型被閘道無預警下架。
這份計畫用夠大的題庫，把閘道上能用的模型都比一遍，回答三個問題：

1. **換模型能不能更準或更便宜**？閘道建議改用 `gpt-6-luna`＋推理 high，要先量過才換（漏判是絕對禁止項）。
2. **不花 OpenAI 額度的開源模型做得到什麼程度**？夠好的話可以當備援，或用來跑每週評測。
3. **知識庫比單用 AI 多帶來多少**？表格最後一列「完整系統」。

判的是「有風險（詐騙＋假訊息）vs 安全」。嵌入模型比較併在 `docs/test/信心程度驗證計畫.md`（第 3 節第 6 步），
兩份一起做、目標 2026-12-03 期末成果展。

## 1. 題目（凍結一份，各模型答同一批）

- **2,000 題**：有風險 1,000（SCAM＋MISINFO）、安全 1,000。這個題數下準確率的 95% 信賴區間約 ±2 個百分點，
  逐題配對比較（McNemar）分得出模型之間幾個百分點的差距；現有 150 題已經飽和，分不出高下。
- 真值全部來自查核機構已發布的結論，收錄規則與每週評測相同（`app/services/factcheck_corpus.py`）：
  有風險取自查核機構已證實的列；安全取自 Cofacts 認可為非謠言的訊息與 MyGoPen／台灣事實查核中心「查核結果為真」的報告
  （語料中約 1,800 則）。
- 詐騙只有約 160 則（多數詐騙訊息在 Cofacts 被標成假訊息，是已知限制），**不另做詐騙單獨的表**。
- 去重：一字不差只算一次；相似度 ≥ 0.90 的同一群只抽一則（做法同信心計畫第 3 節第 4 步），避免同一則謠言佔好幾題。
- 只把查核網址與雜湊寫進 git（`docs/test/results/model_benchmark_items.csv`），**不存訊息原文**（repo 是公開的，Cofacts 訊息可能含個資）。
- 另列兩個子集的數字：**本週新查核**（模型訓練之後才出現）與 **Cofacts**（同一來源、最難分）。

## 2. 模型

| 模型 | 位置 | 花費（OpenAI 額度） |
|------|------|------|
| `gpt-5.6-luna`，推理 medium（正式站現用） | 閘道 OpenAI 相容 | 約 USD 3／2,000 題（實測每題 0.0014） |
| `gpt-6-luna`，推理 high（閘道建議） | 同上 | 試跑後估（單價是 luna 5.6 的一半，但 high 會多用推理 token） |
| `gpt-6-luna`，推理 medium | 同上 | 約 USD 1.5（實測每題 0.0007） |
| `gemma-4-26b-a4b-it` | 學校算力池（Spark） | 不花 |
| `gpt-oss-120b` | 學校算力池 | 不花 |
| `nemotron-3.5-bolt-74b-a9b`、`nemotron-3-super-120b-a12b` | 學校算力池 | 不花 |
| `gpt-oss:20b` | 閘道本地 Ollama | 不花；每題 10～90 秒，只抽 500 題 |

`gpt-5.6-sol`／`-terra`、`gpt-6-sol`、`gpt-6.1-sol` 費率較高，試跑 50 題估過花費再決定要不要列。
微調小模型不在範圍：要 GPU，而且微調後只會給標籤、不會給說明與查核來源，取代不了網站的判讀。

## 3. 作法

- 所有模型用**同一份系統提示**（正式站的 `SYSTEM_PROMPT`，含判定校準）、不帶 web_search、不經快取，量的是模型本身。
- 閘道的 OpenAI 模型走 Responses API（與正式站相同，`ai_service._responses_analyze`）；本地與算力池模型走 `chat/completions`
  （寫法同 `scripts/llm_second_opinion.py`）。回答不是合法 JSON 或判定欄位讀不到的算「格式錯誤」，另列一欄。
- 每個模型先試跑 50 題，量每題耗時與花費，再決定跑全部或抽樣。
- 花費護欄同每週評測：開始前與每 100 題讀 CGU `/me/usage`，保留 USD 3 給網站使用者；隨時可以跑（負責人 2026-10-28），避開週日的每週評測。
- 逐題結果只存網址、雜湊、模型、判定、耗時、花費。

## 4. 表格欄位

| 欄位 | 定義 |
|------|------|
| 準確率 | 風險判定一致的比例（AI 判「無法查證」算錯，與每週評測相同） |
| 精確率／召回率／F1 | 以「有風險」為正類 |
| **漏判** | 有風險判成安全的題數（本系統唯一的絕對禁止項） |
| 無法查證 | 判「無法查證」的比例；另列「作答的準確率」 |
| 格式錯誤 | 回答讀不到判定的比例 |
| 每題耗時 | p50（另列 p90） |
| 每題花費 | USD；算力池與本地模型為 0 |

另附 95% 信賴區間（Wilson）；兩個模型逐題比較用 McNemar 精確檢定（同 `docs/test/results/model_switch_2026-09-30.md`）。

## 5. 最後一列：完整系統

同一批題目模擬網站的流程：先查知識庫（只用比題目早發布的查核；相似度 ≥ 0.75 直接沿用查核結論，即網站的語意快取），
沒命中才用 `gpt-5.6-luna` 的判讀。資料來自信心驗證的同一套計算，不另花額度。這一列和上面各列的差距，就是知識庫帶來的提升。

## 6. 執行需要

同 `docs/test/信心程度驗證計畫.md` 第 6 節：在負責人電腦上跑（本機 `.env`）。一行跑完：`research_run.py benchmark --commit`
（`docs/test/研究批次_本機執行.md` 第 2 節）：每個模型先試跑 50 題，推估剩下的花費不超過 USD 4 才全跑；閘道清單上沒有的模型自動略過。
總花費預估 USD 5～8（luna 兩個模型各跑一次＋試跑），分兩週跑。

## 7. 執行方式（2026-10-28 寫好，尚未執行）

程式：`code/backend/scripts/model_benchmark.py`，在負責人電腦上執行（`freeze`／`run`／`report`；也可用 `research` workflow）；
結果 commit 回研究分支。
要先做完信心驗證的 `corpus-fetch` 與 small 的 `embed`（凍結題庫時用 small 向量去重）。

| 順序 | task | 輸入 | 花費 |
|---|---|---|---|
| 1 | `benchmark-freeze` | — | 不花；只做一次，檔案存在就不覆蓋 |
| 2 | `benchmark-run`（trial） | model、effort、api | 每個模型先 50 題，報告推估跑完的花費 |
| 3 | `benchmark-run` | 同上，取消 trial、max_usd 依試跑結果 | luna 5.6 約 USD 3；6-luna medium 約 1.5 |
| 4 | `benchmark-report` | — | 不花 |

實作細節：

1. **凍結**：有風險取自語料的可入庫列、安全取自語料中已證實為真的列（Cofacts NOT_RUMOR、MyGoPen／台灣事實查核中心「查核結果為真」）。
   同網址或相似度 ≥ 0.90 的同一群只抽一題；凍結前 30 天內發布的新查核先收（每類最多兩成），其餘依固定亂數順序補滿。
   `model_benchmark_items.csv` 只有題號、網址、雜湊、真值、發布日與是否近期；原文每次從語料以雜湊取回（查核網站改了文字的題目會列為找不到）。
2. **呼叫**：閘道的 OpenAI 模型直接用正式站的 `ai_service._responses_analyze`（逾時 `AI_TIMEOUT_SECONDS`＝60 秒、`max_output_tokens`
   2000；推理 high 若因此讀不到判定，就是正式站也會遇到的格式錯誤）。本地與算力池模型走 `chat/completions`（`max_tokens` 4000、
   逾時 300 秒，effort 不是 none 時帶 `reasoning_effort`）。兩者都經過正式站的 `_validate_result`（不認得的 risk_type 會變成 SAFE）。
3. **錯誤**：連線錯誤（逾時、HTTP 錯誤）不算題數，下次續跑時重試；格式錯誤（讀不到判定、缺欄位）算答錯並另列一欄。
4. **花費**：有單價的模型以回應的 tokens 估算；沒有單價的（sol、terra 等）每 20 題讀一次 /me/usage 以實際增加量計算；
   不花 OpenAI 額度的模型（gemma、gpt-oss、nemotron）仍每 100 題確認剩餘額度沒有掉到保留額以下，週日也可以跑。
5. **完整系統**：題目只比對發布日期早於題目的查核（同信心驗證的時間切分），相似度 ≥ 0.75 沿用該筆結論，其餘用 `gpt-5.6-luna`（medium）的判定。
