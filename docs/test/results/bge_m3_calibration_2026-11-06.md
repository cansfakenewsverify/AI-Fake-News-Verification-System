## 4. 給負責人決定

- 語意快取門檻：依規則（噪音帶上緣與改寫帶中位數的中點）算出 **0.84**（正式站查法）。舊模型同一個規則算出 0.76，實際用 0.75。
- 證據信心三個數字見第 3 節；建議先用分位數換算的值，上線後再用每週評測驗證。
- 這些是建議，**負責人同意後**才寫進 `render.yaml`（`SIMILARITY_THRESHOLD`、`EVIDENCE_MID_SIMILARITY`、`SIMILAR_NEWS_MIN`、`EVIDENCE_PATTERN_MARGIN`、`CLAIM_PROTOTYPES_FILE`）。
