## 兩種做法（選一種）

- **A（建議）**：在電腦上開 Claude Code，把這份檔案交給它照做。可以用 Claude Desktop app，或在專案資料夾的終端機執行

- 訊息原文、語料與向量只存在 `code/backend/data/research/`（已 gitignore）；要 commit 的只有 `docs/test/results/` 裡的報告與數字。

## 2. 模型比較（信心驗證的 1-1、1-3 做完之後）

凍結 2,000 題（只做一次；檔案已存在就不會覆蓋）：

```powershell
.\venv\Scripts\python scripts\model_benchmark.py freeze
```

每個模型先試跑 50 題，看「剩下 … 題約 USD …」再決定要不要全跑。正式站現用的模型：

```powershell
.\venv\Scripts\python scripts\model_benchmark.py run --model gpt-5.6-luna --effort medium --api responses --limit 50 --max-usd 0.2
```

全跑（約 USD 3）：

```powershell
.\venv\Scripts\python scripts\model_benchmark.py run --model gpt-5.6-luna --effort medium --api responses --max-usd 3.5
```

其他模型換 `--model`／`--effort`／`--api`：`gpt-6-luna`＋`high` 或 `medium`（`--api responses`）；
算力池與本地模型 `gpt-oss-120b`、`gemma-4-26b-a4b-it`、`nemotron-3.5-bolt-74b-a9b`、`nemotron-3-super-120b-a12b`、`gpt-oss:20b`
用 `--api chat`（不支援推理強度的模型用 `--effort none`）。中斷了重跑同一行指令會從沒做完的題目接著做。

出報告（`docs\test\results\model_benchmark_<日期>.md`），再照 1-5 commit：

```powershell
.\venv\Scripts\python scripts\model_benchmark.py report
```

## 出問題時

- 「讀不到 CGU /me/usage」：`.env` 的 `CGU_API_KEY` 沒設或失效（`scripts\test_ai_provider.py --provider cgu` 可確認）。
- 「沒有可用額度」：本週剩餘額度扣掉保留額 USD 3 後不夠，等週四重置。
- 「questions have no … vector」：先跑對應 embedding 的 `embed`。
- 主控台出現 `?`：cp950 印不出 ≥、– 等符號，不影響結果；報告檔是 UTF-8。
