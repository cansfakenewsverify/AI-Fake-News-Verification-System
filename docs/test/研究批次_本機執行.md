# 研究批次：在負責人電腦上執行

信心程度驗證（`信心程度驗證計畫.md`）與模型比較（`模型比較計畫.md`）要呼叫 CGU、抓查核網站。
負責人 2026-10-28 決定不在 GitHub 設 secret，改在自己的電腦上跑：程式從本機 `code/backend/.env` 讀金鑰，
金鑰不離開這台電腦。雲端的 Claude Code 只負責寫程式與離線測試。

## 兩種做法（選一種）

- **A（建議）**：在電腦上開 Claude Code，把這份檔案交給它照做。可以用 Claude Desktop app，或在專案資料夾的終端機執行
  `claude remote-control`，之後在 Claude Code app 裡就看得到這個 session。它會讀 AGENTS.md：`.env` 只給程式讀，它自己不打開。
- **B**：自己在 PowerShell 照下面的指令跑。

## 護欄（程式會自動擋，不必自己算）

- 隨時可以跑（負責人 2026-10-28：不必等週四額度重置）。
- 會花錢的步驟開始前與每 100 題讀一次 CGU `/me/usage`，保留 USD 3 給網站使用者；超過上限就停。
- 每個 embedding、每個模型都先試跑 50 筆，推估全部的花費不超過上限才全跑（上限：small USD 0.5、large USD 2、每個判讀模型 USD 4）。
- 台灣時間週日不跑花錢的步驟（週日 21:17 有每週評測要用額度）；不花 OpenAI 額度的模型（學校算力池、本地模型）週日照跑。
- 訊息原文、語料與向量只存在 `code/backend/data/research/`（已 gitignore）；`--commit` 只 commit `docs/test/results/` 裡的報告與數字。
- 中斷了（關機、斷線）重跑同一行指令會接著做。

## 1. 信心程度驗證（一行跑完）

第一次約 40 分鐘（抓資料 20～30 分鐘、算向量約 10 分鐘），花費約 USD 0.25。報告：`docs\test\results\confidence_validation_<日期>.md`。

```powershell
.\venv\Scripts\python scripts\research_run.py confidence --commit
```

## 2. 模型比較（一行跑完）

會依序跑 8 個模型設定（`gpt-5.6-luna` medium、`gpt-6-luna` high 與 medium、學校算力池的 `gpt-oss-120b`、`gemma-4-26b-a4b-it`、
兩個 nemotron，以及本地的 `gpt-oss:20b` 抽 500 題）。閘道清單上沒有的模型會自動略過。
花費約 USD 5～8（只有 luna 兩個模型花錢）；本地與算力池模型慢，全部跑完要好幾個小時，可以放著跑，中斷了重跑同一行。
報告：`docs\test\results\model_benchmark_<日期>.md`。需要第 1 節的語料與向量；還沒有的話會先自己做。

```powershell

```

只跑某幾個模型（格式：模型/推理強度/api，逗號分隔）：

## 3. 每三天更新一次資料

重抓三個查核機構的新資料、為新文字補算向量（只有新文字的花費，通常不到 USD 0.01）。三天內更新過就自動略過，所以多跑幾次也沒關係。

```powershell
.\venv\Scripts\python scripts\research_run.py update --commit
```

讓 Windows 每三天自動跑一次（工作排程器；電腦沒開機的話，下次開機後補跑）。在專案資料夾（不是 `code\backend`）依序執行：

```powershell
$backend = (Resolve-Path .\code\backend).Path
```

```powershell
$action = New-ScheduledTaskAction -Execute "$backend\venv\Scripts\python.exe" -Argument "scripts\research_run.py update --commit" -WorkingDirectory $backend
```

```powershell
$trigger = New-ScheduledTaskTrigger -Daily -DaysInterval 3 -At 9:23am
```

```powershell
Register-ScheduledTask -TaskName "FNV-research-update" -Action $action -Trigger $trigger -Settings (New-ScheduledTaskSettingsSet -StartWhenAvailable)
```

注意：排程跑的時候，這個資料夾要停在研究分支（程式只在這個分支上）；不在研究分支時不會 commit。不要了就刪掉：

```powershell
Unregister-ScheduledTask -TaskName "FNV-research-update" -Confirm:$false
```

正式網站的知識庫不用這一步：GitHub Actions 的 `factcheck-sync` 每天 08:07、20:07 已經自動抓查核機構的新結論（CLAUDE.md 第 3 節）。

每週評測的新題目（每週日晚上之後）在 main 上；要加進信心驗證時先把 main 合進來，再跑第 1 節：

```powershell
git merge origin/main
```

## 附錄：單一步驟的指令

需要單獨重做某一步時用（`research_run.py` 就是依序呼叫這些）：

| 做什麼 | 指令（在 `code\backend`） |
|---|---|
| 抓資料 | `.\venv\Scripts\python scripts\confidence_validation.py fetch`（加 `--refresh` 重抓） |
| 算向量 | `.\venv\Scripts\python scripts\confidence_validation.py embed --model text-embedding-3-small --limit 50 --max-usd 0.05`（拿掉 `--limit 50` 全算） |
| 信心分析 | `.\venv\Scripts\python scripts\confidence_validation.py analyze` |
| 凍結題庫 | `.\venv\Scripts\python scripts\model_benchmark.py freeze` |
| 跑一個模型 | `.\venv\Scripts\python scripts\model_benchmark.py run --model gpt-5.6-luna --effort medium --api responses --limit 50 --max-usd 0.2` |
| 模型比較報告 | `.\venv\Scripts\python scripts\model_benchmark.py report` |

## 出問題時

- 「讀不到 CGU /me/usage」：`.env` 的 `CGU_API_KEY` 沒設或失效（`.\venv\Scripts\python scripts\test_ai_provider.py --provider cgu` 可確認）。
- 「沒有可用額度」：本週剩餘額度扣掉保留額 USD 3 後不夠，額度週四重置。
- 某個模型「試跑沒有任何回答」：多半是閘道不支援那個模型或參數（例如推理強度），看上面印出的 HTTP 錯誤碼。
- 主控台出現 `?`：cp950 印不出 ≥、– 等符號，不影響結果；報告檔是 UTF-8。
- `git push failed`：自己在專案資料夾執行 `git push`。
