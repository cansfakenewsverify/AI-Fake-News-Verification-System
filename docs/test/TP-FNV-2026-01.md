## 2. 簡介

### 2.1 計畫目的

驗證「全民查證公社」重做版本（2026-09-15 起一週重做）是否達到進度報告與 3 分鐘 demo 影片的交付條件，並以可量測、可重跑的準則留下證據，供進度報告與論文引用。

**產品定位**（spec §1）：台灣繁中的假訊息／詐騙查證平台——貼上文字或網址（圖片為 P1），AI 判定 SCAM／MISINFO／SAFE 並附查核來源；同一套判定在 Threads 上 @機器人 即可取得，網站結果可一鍵分享回 Threads。

**測試目標**（spec §1 成功定義，依報告週範圍調整）：

1. 進度報告與 3 分鐘 demo 影片如期交出。
2. 影片完整呈現閉環：Threads 可疑貼文 → Tester 回覆並 @機器人 → 機器人回覆紅／黃／綠燈號＋來源＋`/r/{id}` 連結 → 手機版結果頁 → 「分享到 Threads」。報告週 Threads 採模擬模式（FR-10）呈現同一閉環，實機串接排在報告後。
3. 網站四個主畫面（首頁／結果頁／熱門牆／知識庫）在手機寬度可用；淺色為預設；紅黃綠只出現在判定。
4. AI 實際可用（CGU AIR `gpt-5.4-mini`，provider 鏈 `['cgu']`）：至少一次「未命中快取 → AI 判定」與一次「改寫版命中向量快取（`cache_layer="vector"`）」；全程無「AI 分析暫時無法使用」畫面。
5. `pytest tests` 全綠、CI 通過；評測數字（前一版模型 accuracy 96.0%／FN=0 與 CGU `gpt-5.4-mini` 新跑值並列）與三層快取證據可供報告引用。
6. demo 資料乾淨：畫面上每一個「查核來源」皆為 Tier 1／2；熱門牆無 Google News 轉址；知識庫頁不出現 `verified=false` 記錄；找不到查核來源時明示「尚無查核機構證實」且不出現綠燈。
