# 情境劇出片步驟（負責人電腦，2026-11-02）

在負責人電腦上跑，約 30 分鐘（render 最久）。每一行分開貼進 PowerShell。
語意比對還沒接好也能先出一版（學校 2026-11-03 因資安考量關閉 API 與外部模型，閘道沒有 embedding）：煮蛋那段的網站畫面會先顯示「網站畫面待補」，右下角標「預覽版」。

## A. 現在就能做（預覽版）

1. 到專案資料夾（換成你電腦上的路徑）：

```
cd 你的專案資料夾\AI-Fake-News-Verification-System
```

2. 拉最新的分鏡、程式和你們拍的 4 支影片：

```
git pull origin claude/github-project-relevance-gunvht
```

3. 進影片專案：

```
cd video\hf-scenario
```

4. 產生旁白語音（微軟免費語音，不經過學校系統）：

```
..\..\code\backend\venv\Scripts\python tools\tts.py
```

5. 錄「查不到的時候」那段網站畫面（快取命中，不花 AI 額度，語意比對沒接好也能錄）：

```
node tools\capture.mjs site_unverifiable
```

6. 組合成影片的設定：

```
node tools\build.mjs
```

7. render（最久，2026-11-02 實測 22 分鐘）：

```
npm run render
```

成品在 `video\hf-scenario\renders\scenario.mp4`。這個指令已經加了 `--sdr`：你們拍的 4 支影片是手機 HDR，
不加的話 render 到第一個實拍鏡頭就會失敗。會印出 S02、S03、S10 關鍵影格太稀的警告，2026-11-02 檢查成品沒有卡住，可以不管。

如果第 6 步說找不到配樂或音效（`assets/audio/mixkit`），先跑下面兩行再回到第 6 步：

```
..\..\code\backend\venv\Scripts\python tools\mixkit.py
```

```
..\..\code\backend\venv\Scripts\python tools\sfx.py
```

## B. 語意比對接好之後（換成正式版）

1. 手機打開 `https://fakenewsverify.vercel.app/api/health`，`ai_available` 是 true、`embedding` 的 `ok` 是 true。
2. 錄煮蛋那段的網站畫面（第一次會用一次 AI 判讀，約 USD 0.0014）：

```
node tools\capture.mjs site_egg
```

3. 錄 Threads（T1，做法在 `01_真人劇本.md`「拍之前要準備的」），存成 `video\hf-scenario\raw\T1.mp4`，告訴 Claude；
   Claude 設好剪接點後，再跑一次 A 的第 6、7 步。
4. 沒有 T1 也能出片：Threads 那段會是標明「示意畫面」的重繪畫面。

## 出片之後

把 `scenario.mp4` 傳給 Claude（Google Drive 連結就可以），Claude 會放到網站上能直接播放的位置並更新簡報資料夾的 README；
推到 main 才會上線，那一步會先問負責人。
