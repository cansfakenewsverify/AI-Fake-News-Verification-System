# 一、詞彙表（參考第四章）

> 系統名稱：**全民查證公社 — AI 假訊息與詐騙查證系統**
> 詞彙表記錄本系統領域中出現的重要名詞與概念，欄位為：**詞彙 / 定義（解釋）/ 備註**。

## 1.1 詞彙表（Glossary）

| 詞彙 | 定義（解釋） | 備註 |
|------|-------------|------|
| 查證內容 | 使用者提交給系統判斷真偽的訊息，可為文字、網址、圖片或影片 | 系統的核心輸入 |
| 風險類型（risk_type） | 系統對查證內容的判定結果，分為 SCAM / MISINFO / SAFE 三類 | 對外回傳欄位 |
| SCAM（詐騙） | 意圖騙取金錢或個資的訊息 | 如投資詐騙、釣魚、假冒親友 |
| MISINFO（假訊息） | 製造恐慌或誤導大眾的不實訊息 | 如健康謠言、政治謠言、舊聞重炒 |
| SAFE（安全） | 經查證為正確或來自官方的可信資訊 | 如政府公告、官方衛教 |
| PENDING（未查證） | 尚未取得明確查核結果的項目 | 熱門新聞抓取後預設狀態 |
| 風險分類（category） | 風險類型下更細的子分類 | 如 Investment、Phishing、Health_Rumor |
| 信心等級 | 模型對其判定的自評信心，分為高／中／低 | 由 confidence_score 換算；未經機率校準 |
| 信心分數（confidence_score） | 模型自評的 0.0–1.0 數值 | 非真實命中機率，僅供參考 |
| 查證摘要（summary） | 對查證內容的精簡描述 | 同時用於向量資料庫比對 |
| 詳細解釋（explanation） | 以白話說明判定理由，並指出正確事實 | 呈現給使用者 |
| 佐證來源（sources） | 支持判定結果的真實參考連結 | 由 web_search 或查核文章提供 |
| 三層快取 | 為節省 AI 呼叫所設計的多層查詢機制 | URL → Hash → 向量 → AI |
| URL 快取（Layer 0） | 以網址為鍵的快取，相同網址直接回傳既有結果 | 最快、零成本 |
| Hash 快取（Layer 1） | 以內容 SHA-256 雜湊為鍵的快取，完全相同內容命中 | 零成本 |
| 向量快取（Layer 2） | 以語義向量餘弦相似度比對，相似內容命中 | 門檻 0.88 |
| 語義向量（embedding） | 將文字轉成的數值陣列，用於相似度比對 | 1536 維 |
| 餘弦相似度 | 兩個向量夾角的相似程度，0~1 之間 | ≥ 門檻才算命中 |
| 知識庫（knowledge_base） | 儲存已查證內容與其向量的資料庫 | Parquet 檔 |
| AI 分析（Layer 3） | 三層快取皆未命中時，呼叫 AI 引擎進行判定 | 最耗資源 |
| AI 引擎 | 執行內容判定的大型語言模型服務 | gpt-5-mini 主、Claude 備援 |
| 中繼閘道 | 學校提供的 OpenAI 相容 API 代理 | myai168 / CGU AIR |
| web_search（即時佐證） | AI 即時上網搜尋以取得真實來源 | 提升判定可靠度 |
| 今日熱門趨勢 | 系統自動蒐集的熱門查核新聞列表 | 來源 MyGoPen/TFC/Cofacts |
| 查核來源 | 提供已查核假訊息的外部單位 | MyGoPen、台灣事實查核中心、Cofacts |
| 自動抓取 | 排程器定期上網蒐集查核新聞並寫入系統 | 預設關閉以節省資源 |
| 排程器（Scheduler） | 依時間自動觸發抓取任務的元件 | 對應 actor「時間」 |
| 假訊息索引 | 從查核文章擷取原始謠言並存入知識庫 | 供日後相同輸入命中 |
| 任務（Task） | 一次非同步查證請求的處理單位 | 含狀態與結果 |
| 任務狀態 | 任務的處理階段：pending / processing / completed / failed | 前端輪詢用 |
| 輪詢（polling） | 前端定期向後端詢問任務是否完成 | 每 2 秒一次 |
| 同步查證 | 一次請求直接回傳最終結果的查證方式 | 適合手機捷徑 |
| 人工覆寫 | 管理員手動修正系統的判定結果 | 對應 admin 功能 |
| 使用者回饋 | 使用者對查證結果的評分或意見 | 供改進參考 |
| 爬蟲（Crawler） | 擷取網址、圖片、影片內容的元件 | Trafilatura / yt-dlp |
| 逐字稿 | 將影片語音轉成的文字 | 字幕優先，否則 whisper |
| 語音轉文字（STT） | 把影片音訊轉成文字的服務 | whisper 模型 |
| 評測（Evaluation） | 以標註資料量測判定引擎效能 | 產出 accuracy/F1/混淆矩陣 |
| 偽陽性（False Positive） | 將安全內容誤判為風險 | 誤報 |
| 偽陰性（False Negative） | 將風險內容誤判為安全 | 漏報，最危險 |
